### 1.2 طبقات كشف السيولة (4 طبقات موجودة حالياً)

النظام يعتمد على **4 طبقات** لكشف السيولة:

| الطبقة | الملف | الوظيفة | المدخلات |
|--------|-------|---------|----------|
| **1. Structure** | `structure.mjs` | Pivots + EQH/EQL + Sweeps + FVG | شموع خام |
| **2. Derivatives** | `derivatives.mjs` | OI + Funding + L/S Ratio + CVD | Futures REST + Taker Buy |
| **3. Orderbook** | `orderbook.mjs` | Book Imbalance + Iceberg + Spoof + Liq Map | Depth + AggTrades |
| **4. Score** | `score.mjs` | تجميع الإشارات → درجة 0-100 | نواتج الطبقات الثلاث |

### 1.3 مكوّنات المراقبة الحية (Engine)

- **Polling كل 3 ثوانٍ** على كل عملة.
- كشف **لمس المنطقة** (zone crossing).
- كشف **CHoCH up** (BSL → SSL → تجاوز BSL صعوداً).
- **تنبيهات** عند المهلة (افتراضي 30 دقيقة).

## ⚠️ الجزء الثالث: الفجوات (Gaps) — ما ينقص لتطبيق منطق Fabio كاملاً

### 3.1 الفجوات الجوهرية (Critical Gaps)

| الفجوة | السبب | التأثير |
|--------|-------|--------|
| **❌ لا يوجد Volume Profile حقيقي** | النظام يعتمد فقط على Pivots ولا يحسب POC/VAL/VAH/LVN | لا يمكن تطبيق منطق "المال الحر" أو LVN كمستهدف |
| **❌ لا يوجد Aggregation Order Flow بفلاتر العقود** | لا يوجد فلتر "30 عقد NYSE / 20 عقد لندن" | لا يمكن محاكاة "الفقاعات" في تدفق الأوامر |
| **❌ لا يوجد مفهوم Balance vs Imbalance صريح** | النظام يعرف trend (up/down) فقط | لا يمكن تطبيق "الخطوة 1: الموقع" في نموذج فابيو |
| **❌ لا يوجد نموذج 3 خطوات منظم** | النموذج implicit في الـ score | لا يوجد منطق صريح لـ (Context → Validation → Aggression) |
| **❌ لا يوجد Session-Based Detection** | لا يوجد فلتر New York vs London | لا يمكن تطبيق "جلسة نيويورك = الأفضل" |
| **❌ لا يوجد Absorption Detection (Punch the Wall)** | النظام فيه Iceberg لكن ليس Punch-the-Wall | لا يمكن كشف "محاولات كسر فاشلة" |
| **❌ لا يوجد Mean Reversion Model** | فقط trend-following | لا يمكن تطبيق "نموذج العودة للمتوسط" للجلسات الأخرى |
| **❌ لا يوجد Narrative/Story Tracking** | لا يوجد متتبع للسرد | لا يمكن تطبيق "بناء الـ narrative" |

### 3.2 فجوات ثانوية (Secondary Gaps)

| الفجوة | الأهمية |
|--------|---------|
| **❌ لا يوجد Risk Management مدمج** | لا يحسب المخاطرة 0.25-0.5% |
| **❌ لا يوجد Break-Even Logic** | لا يحرك SL تلقائياً |
| **❌ لا يوجد R:R Calculator** | لا يحسب نسبة المخاطرة/المكافأة |
| **❌ لا يوجد News Filter** | لا يستثني الأحداث الكبرى مثل قصف إيران |

| **❌ لا يوجد Walk-Forward / Calibration Display** | المعايرة موجودة لكن غير ظاهرة للمستخدم |

### 4.2 المرحلة الثانية: نموذج الـ 3 خطوات (الأسبوع 2)

##### `server/liquidity/threeStepModel.mjs`

```javascript
// تطبيق النموذج الثلاثي لـ Fabio Valentino

export function evaluateThreeStepModel({
  symbol,
  timeframe,
  location,        // من location.mjs
  levelValidation, // من volumeProfile.mjs + pivots
  aggression       // من bubbles.mjs + absorption.mjs
}) {
  // الخطوة 1: الموقع - هل نحن خارج التوازن؟
  const step1 = {
    passed: location.state !== 'balance',
    score: location.confidence,
    reason: location.narrative
  };
  
  // الخطوة 2: التحقق من المستوى - هل وصلنا لمنطقة سيولة؟
  const step2 = {
    passed: levelValidation.isValidZone,
    score: levelValidation.strength,
    reason: levelValidation.zoneDescription
  };
  
  // الخطوة 3: الزناد العدواني - هل هناك عدوان؟
  const step3 = {
    passed: aggression.hasAggression,
    score: aggression.intensity,
    reason: aggression.description
  };
  
  // Fabio: "0.25% - 0.5% risk, R:R >= 1:2"
  const overallScore = (step1.score + step2.score + step3.score) / 3;
  
  return {
    setup: step1.passed && step2.passed && step3.passed,
    score: overallScore,
    steps: { step1, step2, step3 },
    riskManagement: {
      riskPct: '0.25-0.5',
      rr: '1:2 minimum',
      stopLoss: step2.zoneType === 'BSL' ? 'below_high' : 'above_low'
    },
    action: step1.passed && step2.passed && step3.passed 
      ? 'EXECUTE' 
      : step1.passed && step2.passed 
        ? 'WAIT_FOR_AGGRESSION' 
        : 'STAND_ASIDE'
  };
}
```

// تطبيق قواعد Fabio لإدارة المخاطر:
// - 0.25% - 0.5% لكل صفقة
// - حد أقصى 11 SL يومياً
// - Risk:Reward ≥ 1:2
// - Move to break-even after breakout

export function calculatePositionSize({
  accountSize,
  entryPrice,
  stopLoss,
  targetPrice,
  riskPct = 0.005  // 0.5% افتراضي
}) {
  const riskAmount = accountSize * riskPct;
  const riskPerUnit = Math.abs(entryPrice - stopLoss);
  const positionSize = riskAmount / riskPerUnit;
  const reward = Math.abs(targetPrice - entryPrice);
  const rr = reward / riskPerUnit;
  
  return {
    positionSize,
    riskAmount,
    rewardAmount: positionSize * reward,
    rr,
    valid: rr >= 2
  };
}

export function evaluateDailyRisk(state, maxLosses = 11) {
  // ينبه إذا وصل لعدد SL يومي
  if (state.dailyLossCount >= maxLosses) {
    return { action: 'STOP_TRADING', reason: 'الحد الأقصى اليومي' };
  }
  return { action: 'CONTINUE' };
}
